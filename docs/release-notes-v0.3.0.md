# Boya Automation v0.3.0

This release turns Boya Automation into a bilingual open-source desktop application.

## Highlights

- Switch the complete interface between English and Chinese with one sidebar button.
- The selected language is remembered across launches.
- Added an English README, Chinese README, and real English UI screenshots.
- Added English and Chinese one-click launchers.
- Windows package includes both `BoyaAutomation.exe` and a Chinese-named compatibility build.
- Added gap-filter and localization tests, Windows CI, contribution guidance, and an MIT license.

## Verification

- `6` automated tests pass.
- The packaged English executable launches successfully.
- Background worker startup and graceful stop were verified.
- The bilingual source UI was rendered and checked at high DPI.

## Notes

- Windows 10/11 x64.
- Requires a valid Beihang University SSO account and access to Boya.
- Use dry-run mode first and follow all university rules regarding course selection and attendance.
